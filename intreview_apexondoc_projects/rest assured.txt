FAIL FAST

A fail-fast iterator throws a ConcurrentModificationException if the collection is structurally modified after the iterator is created (except through the iterator's own methods).

List<String> list = new ArrayList<>();
list.add("A");
list.add("B");

for (String s : list) {
    list.add("C"); // Structural modification
}
ALL LIST IS EXAMPLE

FAILS-SAFE

Definition:
A fail-safe iterator does not throw an exception if the collection is modified during iteration. Instead, it iterates over a clone (copy) of the collection.
			CopyOnWriteArrayList

			CopyOnWriteArraySet

			ConcurrentHashMap

		CopyOnWriteArrayList<String> list = new CopyOnWriteArrayList<>();
		list.add("A");
		list.add("B");
		for (String s : list) {
 		   list.add("C"); // No exception
		}
